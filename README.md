## About

This repository brings together university projects, personal experiments, practical exercises, and technical documentation.

Some of the content comes from academic work, while other parts are based on independent exploration and hands-on practice with tools such as Wireshark and tcpdump, including packet analysis, traffic inspection, data interpretation, and network configurations.

---

## Topics of Interest

- **Networking Fundamentals:** Network architectures, communication models, and core concepts.
- **Network Analysis:** Packet inspection, traffic analysis, and protocol interpretation.
- **Network Tools:** Wireshark, tcpdump, and other networking utilities.
- **Network Configuration:** Addressing, routing, and network setup.
- **Protocols:** TCP/IP, DNS, DHCP, HTTP, and other communication protocols.
- **Network Security:** Traffic monitoring and fundamental security concepts.
