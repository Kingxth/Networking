# Networking

A place where I document what I'm learning, the labs I build, the configurations I work on and the technologies I'm exploring in networking.

I'm currently focused on understanding how networks work beyond the basics, experimenting with different configurations and getting more comfortable with network infrastructure.

---

### Topics & Learning

- **Networking Fundamentals** — OSI Model, TCP/IP, subnetting and IPv4 addressing.
- **Routing & Switching** — Static routing, VLANs, trunking and inter-VLAN routing.
- **Routing Protocols** — OSPF, dynamic routing and route propagation.
- **Network Infrastructure** — Routers, switches, WAN connections and network segmentation.
- **Network Security** — SSH, access control and basic network hardening.
- **Troubleshooting** — Connectivity issues, routing tables and protocol debugging.

### Technologies & Tools

- Cisco IOS
- Cisco Packet Tracer
- VLANs & 802.1Q
- OSPF
- IPv4 / Subnetting
- SSH
- CLI Configuration

Hands-on labs involving:
